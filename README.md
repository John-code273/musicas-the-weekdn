# The Weenkdn

## Objetivo

Este projeto tem como objetivo criar um site que apresente informações sobre a banda The Weenkdn, incluindo suas musicas e um pouco sobre eles.

## Funcionalidades

1. Página inicial com links para "Sobre" e "Musicas"
2. Página de "Sobre" com cabeçalho e links
3. Página de "Musicas" com um vídeo e uma lista de musicas e albuns

## Tecnologias utilizadas

1. HTML5
2. CSS3
3. JavaScript

## Como executar

1. Clone o repositório:
   ```bash
   git clone <repositorio-url>
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd <nome-do-projeto>
   ```

3. Inicie o servidor local:
   ```bash
   python -m http.server
   ```

4. Acesse o site em seu navegador:
   ```
   http://127.0.0.1:8000
   ```

## Conceitos de programação presentes

1. Estrutura básica de um site (HTML)
2. Estilos CSS para criar um design personalizado
3. Manipulação de elementos com JavaScript (não utilizado neste projeto)
